# Red Sky v3 — A Market Thesis for an Experiential Entertainment Credit Platform

Interactive single-page brief on the market, the technology, four product directions, and exit pathways for an experiential entertainment credit platform.

Written for a fresh reader. No prior context required. The page explains what the category is, why traditional lenders structurally fail at the $500K–$10M tier, why software is the unlock, and how each of four product directions pays back.

**Live:** https://botsmithgo.github.io/red-sky-v3/

Dark-mode-first, no build step, vanilla HTML/CSS/JS. Open `index.html` to view locally.
